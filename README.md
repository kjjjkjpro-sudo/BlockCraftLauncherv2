# BlockCraft Launcher

A minimal Android launcher for Minecraft Java Edition metadata discovery and launcher readiness checks.

## Features
- Dark Material 3 UI
- Home, Versions, Instances, Accounts, Mods, Settings, and Logs screens
- Navigation using Jetpack Compose Navigation
- Mojang version manifest fetch and parse
- Honest launcher status reporting without faking Minecraft launch support

## Build

./gradlew :app:assembleDebug
